# Character Burner UX roadmap

This records the pre-A–Z UX discussion (CH-06). It is a product handoff, not
RAW, current behavior, or authorization to implement UI in catalog cleanup.
D-005/D-006 and the existing character rules still govern actual state changes.

| Status | Direction |
| --- | --- |
| Accepted | Lifepath history supports undo last and reset all, rather than removing an arbitrary earlier path from the middle of the history. |
| Accepted | Compare lifepaths with pinnable details; highlight available routes back from a candidate on the map. |
| Accepted | Search for lifepaths, show all same-name matches with setting-qualified labels, and navigate the map to the selected result. |
| Accepted | A skill decrement can close the skill at its opening boundary when permitted. Default to Ordinary points and allow an explicit pool choice; refund the exact paid pool. Required-skill and enforcement rules still apply. |
| Accepted | Add Skill has its own search and descriptions. Selecting adds an unopened row, Plus opens it, and a user-added row can be removed under the applicable rules. Selection, opening and spending remain distinct. |
| Proposal | Toggle detailed/compact cards and grants, optionally with a shortcut. Moderate typo tolerance in search; optional root filter for Add Skill. |
| Open | How to preserve stable map placement while supporting arbitrary stocks and custom content; avoid fixed Human-only coordinates. |
| Open | Exact shortcuts, visual treatment of a just-opened skill and route computation. No specific color, hotkey, or search algorithm is approved here. |
